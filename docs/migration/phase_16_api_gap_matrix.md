# PHASE 16 — API GAP MATRIX
## Reliable-Insurance-Backend: Legacy Administrative Entry Points vs FastAPI Contracts

---

### 1. Architectural Scope & Methodological Principles
This matrix reconciles every legacy programmatic entry point and WebForms administrative operation against existing and target FastAPI endpoints.
- **Source of Truth**: Legacy C# source files (`Log_In.aspx.cs`, `adm_UserMaster.aspx.cs`, `Adm_RolePrivilege.aspx.cs`, `ChangePassword.aspx.cs`, `Service.asmx.cs`, `SearchMethods.aspx.cs`, `DAL_Operations.cs`, `BLL_Operations.cs`).
- **Security Baseline**: All modern endpoints strictly require OAuth2 Bearer JWT tokens, enforce server-side RBAC via `require_roles(...)`, and perform principal resolution to prevent IDOR and branch cross-contamination.

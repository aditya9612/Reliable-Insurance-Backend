# Phase 10 — Endorsement Stored Procedure Mapping (`phase_10_endorsement_sp_mapping.md`)

## 1. Overview
This document maps every legacy MySQL stored procedure and inline ADO.NET operation used in the Endorsement and Policy Modification module (`Clerk/EndorsementEntry.aspx.cs`, `Clerk/AppEndorsementList.aspx.cs`, `Clerk/PolicyTransactionNew.aspx.cs`, `Service.asmx.cs`) to the new FastAPI / Async SQLAlchemy 2.x service and repository layer.

---

## 2. Stored Procedure to FastAPI Service Mapping Matrix

| Legacy Stored Procedure | Legacy Caller(s) | Legacy Tables Read / Written | New FastAPI Endpoint | New Service / Repository Method | Parity Behavior & Improvements |
|---|---|---|---|---|---|
| `sp_InsertEndorsement` / `sp_InsertAppEndorsement` | `Clerk/EndorsementEntry.aspx.cs`, `Service.asmx.cs::InsertAppEndorsement` | **R**: `tbl_transaction`, `tbl_customer`, `tbl_vehicledetails`<br>**W**: `tbl_appendorsement` | `POST /api/v1/endorsements` | `ClaimsEndorsementService.create_endorsement` | Validates policy active status (`PolicycancelId == 0`), validates modified fields against the per-type allowlist, captures `before` and `after` field snapshot, computes preview premium/commission deltas, and creates `tbl_appendorsement` in `SUBMITTED` (or `DRAFT`) state. |
| `sp_UpdateEndorsementStatus` (Approve / Reject) | `Clerk/AppEndorsementList.aspx.cs`, `Clerk/EndorsementEntry.aspx.cs` | **R/W**: `tbl_appendorsement` | `POST /api/v1/endorsements/{id}/approve`<br>`POST /api/v1/endorsements/{id}/reject` | `ClaimsEndorsementService.approve_endorsement`<br>`ClaimsEndorsementService.reject_endorsement` | Locks `tbl_appendorsement` (`SELECT ... FOR UPDATE`), enforces RBAC (`ENDORSEMENT_APPROVE_APPLY_ROLES`), and transitions status (`SUBMITTED -> APPROVED` or `REJECTED`). |
| `sp_UpdateTransactionNew_2026` + `sp_UpdateCustomer` + `Sp_UpdateVehicleDetails` | `Clerk/EndorsementEntry.aspx.cs`, `Clerk/PolicyTransactionNew.aspx.cs` | **R/W**: `tbl_appendorsement`, `tbl_transaction`, `tbl_customer`, `tbl_vehicledetails`, `tbl_agentcommissionpayment`, `tbl_franchisecommission`, `tbl_account` | `POST /api/v1/endorsements/{id}/apply` | `ClaimsEndorsementService.apply_endorsement` | Atomically applies allowed field changes to `tbl_customer`, `tbl_vehicledetails`, and `tbl_transaction`, sets `UpdateEntryStatus = 1`, `UpdateEntryRemark`, `CorrectionText`, `IsRecalculate = 1` (for financial changes), updates `PaidAmount`/`OutstandingAmount` or initiates `RefundStatus = "PENDING_APPROVAL"`, adjusts agent/franchise commissions (or records `CommissionRecoveryAmount` if already paid), and posts balanced accounting adjustment rows in `tbl_account`. |
| `sp_UpdateEndorsementStatus` (Reverse) | `Clerk/EndorsementEntry.aspx.cs` | **R/W**: `tbl_appendorsement`, `tbl_transaction`, `tbl_customer`, `tbl_vehicledetails`, `tbl_agentcommissionpayment`, `tbl_franchisecommission`, `tbl_account` | `POST /api/v1/endorsements/{id}/reverse` | `ClaimsEndorsementService.reverse_endorsement` | Restores `before` field snapshot and old premium/commission values on `tbl_transaction`/`tbl_customer`/`tbl_vehicledetails`, posts contra accounting entries in `tbl_account`, and transitions endorsement to `REVERSED`. |
| `sp_SelectEndorsementList` | `Clerk/AppEndorsementList.aspx.cs` | **R**: `tbl_appendorsement`, `tbl_transaction` | `GET /api/v1/endorsements`<br>`GET /api/v1/endorsements/{id}` | `ClaimsEndorsementService.list_endorsements`<br>`ClaimsEndorsementService.get_endorsement` | Lists endorsements with strict role, branch (`BranchId`), and principal (`AgentId`/`FranchiseId`/`SalesExId`) scoping. |
| `sp_ProcessEndorsementRefund` (Legacy Refund Voucher) | `Clerk/EndorsementEntry.aspx.cs` | **R/W**: `tbl_appendorsement`, `tbl_transaction`, `tbl_account`, `tbl_ewallet` | `POST /api/v1/refunds/{endorsement_id}/approve`<br>`POST /api/v1/refunds/{endorsement_id}/disburse`<br>`POST /api/v1/refunds/{endorsement_id}/reverse` | `ClaimsEndorsementService.approve_refund`<br>`ClaimsEndorsementService.disburse_refund`<br>`ClaimsEndorsementService.reverse_refund` | Approves and disburses negative-delta endorsement refunds via Bank/Cheque (`AccTransId = 17`) or E-Wallet credit (`WalletService` / `AccTransId = 14`), with full reversal support (`AccTransId = 18`). |

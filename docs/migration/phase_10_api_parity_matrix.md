## 1. Legacy API & Entry Point Surface Summary

Per `docs/migration/02_legacy_api_inventory.md`, the legacy `InsurancefinalNew` C#/.NET 4.0 surface comprises:
- **339 ASMX WebMethods** in `Service.asmx.cs` (`[WebMethod]`, SOAP + JSON script endpoints)
- **41 AJAX Page WebMethods** in `Clerk/SearchMethods.aspx.cs` (`[WebMethod] public static`)
- **16 App Search WebMethods** in `AppSearchMethod.aspx.cs` (`[WebMethod] public static`)
- **2 Vehicle Lookup WebMethods** in `VehicleService.asmx.cs`
- **18 Inline Page WebMethods** across 11 `Clerk/*.aspx.cs` pages (`PE_TransactionEntry.aspx.cs`, `PolicyTransactionNew.aspx.cs`, `adm_NcbRecovery.aspx.cs`, `adm_PolicyCancel.aspx.cs`, etc.)
- **2 HTTP Handlers (`.ashx`)**: `DownloadAll.ashx.cs` (ZIP document streaming) and `ImageHandler.ashx.cs` (image byte rendering)
- **1 External Webhook Page**: `PolicyParserWebhook.aspx.cs` (HiCaliber OCR JSON callback)
- **213 WebForms (`.aspx`) Server Postback Flows** (`btnSubmit_Click`, `btnApprove_Click`, `gv_RowCommand`, etc.)

The new `Reliable-Insurance-Backend` consolidates these WebMethods and WebForms postbacks into **78 RESTful JSON endpoints** across 15 domain routers mounted under `/api/v1` (`app/api/v1/router.py`).
